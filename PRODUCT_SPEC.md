# PRODUCT SPECIFICATION: SKILLFORGE

## 1. Product Vision
**SkillForge** by **Code404** is a premium, production-quality EdTech and career-development platform. Its mission is to bridge the gap between classroom education and high-paying careers in technology by providing students and aspiring professionals with a structured, rigorous, and interactive path to career readiness.

### Tagline
> Learn. Build. Practice. Get Hired.

### The Problem
Traditional education programs teach theory but fail to provide structured guidance on:
- What exactly to learn for specific industry roles.
- The order in which to learn skills.
- High-quality resources and hands-on practice.
- Building production-grade projects.
- Placement and interview preparation.
- Continuous progress tracking.

### The SkillForge Journey (Core Engine)
The platform is organized around a highly structured, sequential journey:
1. **DISCOVER**: Self-assessment and interest alignment to select a Career Path.
2. **LEARN**: Step-by-step modular learning through high-quality curated curriculum.
3. **PRACTICE**: In-browser coding challenges, quizzes, and aptitude tests.
4. **BUILD**: Developing real-world, industry-standard projects.
5. **PREPARE**: Mock interviews, resume builder, and company-specific prep.
6. **GET HIRED**: Direct pipelines to hiring partners, verified achievement showcase, and recruiter matching.

## 3. Product Architecture & Modules

### 3.1. Career Roadmaps (The Compass)
- Visual, interactive, and branchable roadmaps for major tech roles (e.g., Software Engineer, Frontend Developer, Backend Developer, AI/ML Engineer).
- Clear mapping of roadmap steps to actual courses and modules.

### 3.2. Learning Management System (LMS)
- **Courses**: Comprehensive deep dives containing Modules and Lessons.
- **Lessons**: Rich text, video, embedded code snippets, interactive code playgrounds, and downloadable resources.

### 3.3. Practice & Assessment Engine
- **Quizzes & Aptitude Tests**: Timed, multiple-choice questions for foundational logic.
- **Coding Sandbox**: In-browser execution of coding challenges (JS/TS, Python, C/C++, Java).
- **Assessments**: Milestone checkpoints that unlock certificates.

### 3.4. Project Hub (The Forge)
- Instead of simple tutorials, SkillForge guides students through complex, multi-step, production-grade projects.
- Project instructions are broken down into Tasks with auto-verification steps (code check, linting, tests).

### 3.5. Placement & Interview Preparation
- **Resume Builder**: Generates clean, ATS-optimized markdown/PDF resumes from user profile data.
- **Interview QA Bank**: Searchable database of real interview questions tagged by company, role, and difficulty.
- **Mock Interviews**: Interactive simulated interviews with feedback.

### 3.6. Certification & Verification
- Secure, cryptographically verifiable certificates issued on course and project completion.
- Each certificate is associated with a public verification URL showing student accomplishments, project repository links, and assessment scores.

## 4. User Personas & Permissions

| Role | Description | Core Capabilities |
| :--- | :--- | :--- |
| **Guest** | Unauthenticated visitor | Browse landing page, preview public roadmaps, view public certificate verifications. |
| **Student** | Registered learner | Enroll in roadmaps, take courses, complete coding challenges, build projects, generate resumes, earn certificates. |
| **Instructor** | Content creator | Author courses, create modules/lessons, design coding challenges, write project specs, review student projects. |
| **Admin** | System manager | User management, content moderation, analytics review, certificate revocation, managing premium tier parameters. |
| **Super Admin** | System owner / Code404 team | Full system control, database access, system configurations, audit log inspection, billing configuration. |

## 5. Development Phases (Strategic Rollout)
To build a stable, professional product, development is strictly staged:
* **Phase 1 (Current)**: Architecture, database schema, design system tokens, and premium landing page foundation.
* **Phase 2**: Authentication, database implementation, and personal Student Dashboard.
* **Phase 3**: Career Roadmaps & Learning System (Courses, Modules, Lessons).
* **Phase 4**: In-browser Practice, Aptitude Tests, and Coding Sandbox.
* **Phase 5**: Guided Projects with task trackers.
* **Phase 6**: Placement Prep, Resume Builder, and Company QA Bank.
* **Phase 7**: Cryptographic Certificates & Verification Portal.
* **Phase 8**: Premium Subscriptions & Billing.
* **Phase 9**: Advanced AI Features (personalized paths, AI code review, mock interviews).
